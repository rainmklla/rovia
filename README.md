# Rovia

A travel destinations website built with React. Browse 12 destinations across six regions, filter by region, and open a detail page for each one.

**Live demo:** https://YOUR-ROVIA-URL.vercel.app

## Features

- Home page with a video hero and a featured section built from the top-rated destinations
- Destinations page with region filters
- Dynamic detail page for each destination, driven by the URL
- Shared layout with navbar and footer
- Custom 404 page
- All destination data in a single source file

## Tech Stack

React 19, React Router 7, Vite, JavaScript, CSS

## Run Locally

```bash
git clone https://github.com/rainmklla/rovia.git
cd rovia
npm install
npm run dev
```

## Status

Front-end only. The My Trips page is a placeholder, and trip saving and booking are planned next.
